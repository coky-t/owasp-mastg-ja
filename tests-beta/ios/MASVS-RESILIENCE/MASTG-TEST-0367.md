## 概要

このテストは、一般的な仮想デバイス検出メカニズムへのフックを試みることで、アプリが iOS 仮想デバイス ([Corellium](../../../tools/generic/MASTG-TOOL-0108.md) など) の存在を検出するチェックを実装しているかどうかを検証します。

アプリケーションによって実行される仮想デバイス検出メカニズムやパターンに関する詳細な概要については [仮想デバイス検出 (Virtual Devices Detection)](../../../knowledge/ios/MASVS-RESILIENCE/MASTG-KNOW-0135.md) を参照してください。

> [!NOTE]
> "スコープ外"  
> このテストはこれらのメカニズムの堅牢性や有効性をカバーしていません。自動テストのみでの評価することは非常に困難であり、手動でのリバースエンジニアリングとカスタム計装を必要とする可能性があります。仮想デバイス検出を効果的に実装するベストプラクティスについては [仮想デバイスに対する堅牢化 (Hardening Against Virtual Devices)](../../../best-practices/MASTG-BEST-0053.md) を参照してください。

## 手順

1. [アプリのインストール (Installing Apps)](../../../techniques/ios/MASTG-TECH-0056.md) を使用して、アプリをインストールします。
2. [メソッドフック (Method Hooking)](../../../techniques/ios/MASTG-TECH-0095.md) を使用して、関連する API コールをフックします。
3. アプリを徹底的に動かして、できるだけ多くのフローをトリガーし、可能な限り機密データを入力します。

## 結果

出力には仮想デバイス検出チェックのインスタンスと、フックされたメソッドや API を含む可能性があります。

## 評価

仮想デバイス検出チェックのインスタンスが観測されない場合、そのテストケースは不合格です。

**予想される検出漏れ:**

使用されるフックやトレースによってカバーされていない仮想デバイス検出メカニズムをアプリが使用している場合、あるいは仮想デバイス検出ロジックが検出を回避する (たとえば、難読化、動的コードローディング、アンチ計装技法など) 方法で実装されている場合、このテストは検出漏れを生じる可能性があります。そのような場合、検出結果が何もないとしても仮想デバイス検出が存在しないことを保証するものではありませんし、仮想デバイス検出メカニズムを特定して解析するには、追加の手動リバースエンジニアリングやカスタム計装が必要となることがあります。
